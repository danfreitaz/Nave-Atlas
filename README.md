# Nave Atlas

Versão pública do portal Atlas, um universo de Danilo Freitas Souza.

Site: https://danfreitaz.github.io/Nave-Atlas/

Este repositório contém a home compilada, suas imagens e quatro músicas. Os documentos internos, fichas completas e o código de desenvolvimento ficam no repositório privado de origem.

## Publicação

Em Settings → Pages: Source = Deploy from a branch; Branch = main; pasta = / (root).

O arquivo `.nojekyll` mantém os arquivos estáticos sem processamento Jekyll. Todos os caminhos são relativos para funcionar dentro de `/Nave-Atlas/`.

## Conteúdo

- Apresentação do universo Atlas.
- Exploração de 21 ambientes e sete tripulantes.
- Busca e arquivo editorial.
- Player com quatro músicas.
- Relatórios FTBA e Storytelling Studio identificados como módulos em preparação.

Publicação inicial: novembro de 2026.
